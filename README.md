## 保留与限制

原有 `index.html` 的 150 张词卡、36 条标牌、12 关阅读、测验及进度全部保留。v1.1.0 已在原主页加入醒目的“3 天速成训练”入口，并统一首页与练习页的视觉样式；原卡片中的相关错误提示仍未直接改写。新页“来源与勘误”明确列出九／米饭同为降调、礼貌词的回答功能、`ไม่ได้` 的语境区别，使用原卡片时请对照。

本轮**没有**真人自然语速／连读、泰式英语或泰北话录音，也没有真实招牌照片或内嵌字体。字重／布局变化不等于跨字体能力验证。不得把设备标准泰语合成当作地方口音录音。自编练习情境的真人自然度仍待核听。

价格页仅重新核对了官方活动示例；十项市场范围没有得到新的当前核验。页面列出逐项来源和这个限制；不能把参考区间当作官方定价。

## 本地查看与测试

在仓库目录运行：

```sh
python -m http.server 8765
```

打开 `http://localhost:8765/practice.html`。不要仅用文件预览判断脚本、语音或缓存是否工作。

测试使用 Python、Playwright、Chromium 和 Node.js（建议 18 或更高版本）：

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/test_practice.py
node tests/test_sw.cjs
```

脚本不修改仓库源码，也不访问真实用户记录。界面测试在 Chromium 内存页面中运行，语音与存储为明确标注的模拟接口；缓存测试使用合成 Cache/Fetch。它们不能证明真实网页跳转、手机音质或设备离线语音可用。应另外用实际 iPhone／手表开飞行模式测试两个页面及语音。

本轮编辑环境不允许浏览器导航到 HTTP 或 file URL；没有关闭或绕过该限制。实测结果：界面 119 项断言通过，缓存逻辑 14 项断言通过，无浏览器脚本错误。真实浏览器 Service Worker 注册及飞行模式切换为 NOT_RUN。
