## 速成练习内容

`practice.html` 是可单独保存的静态页面，不依赖第三方脚本、账号或在线 API。

1. 14 个金额 × 3 种计价表达的随机题，分别填写金额、单位与两人总额；支持阿拉伯数字、泰文数字与合法千位分隔。
2. 8 个否定／顺序辨认题，含 `ไม่ได้ไป` 与 `ไปไม่ได้`。
3. 8 个确认与接车、附加收费情境；6 张可给对方看的大字英文确认卡。
4. 12 个高价值标牌的词块教学、去提示测验和字重／布局变化练习；零基础入口先引导至字母课。
5. 泰北话四组识别桥梁、来源与勘误、三天学习清单。
6. 三个页面一同预缓存；离线时精确返回请求的页面。

速成进度保存在 `chiangmai-practice-v1`，不会读取或覆盖原版 `chiangmai-ear-v1`。字母课使用第三个独立键 `chiangmai-alphabet-v1`。
文字、合成听音、请求确认、去提示认字分别记录；请求确认不计作独立听懂。

## 保留与限制

原有 `index.html` 的 150 张词卡、36 条标牌、12 关阅读、测验及进度全部保留。v1.2.0 已修正原卡片中上述三项简化提示。速成页“来源与勘误”保留解释与核对链接。

本版没有真人自然语速／连读、泰式英语或泰北话录音，也没有真实招牌照片或内嵌字体。字重／布局变化不等于跨字体能力验证。不得把设备标准泰语合成当作地方口音录音。自编练习情境的真人自然度仍待核听。

字母课区分字母名与拼词起音；辨认字形或组对部件不代表能独立读出全部陌生词。元音组合、字尾变化与声调只用具体例子引导，不提供未经核验的自动拼音生成器。描形板只辅助记形，不评定笔顺或手写正确性。

价格页此前只重新核对了两个官方活动示例；十项市场范围没有得到新的当前核验。不能把参考区间当作官方定价。

## 本地查看与测试

在仓库目录运行：

```sh
python -m http.server 8765
```

打开 `http://localhost:8765/alphabet.html`。不要仅用文件预览判断脚本、语音或缓存是否工作。

测试使用 Python、Playwright、Chromium 和支持全局 Fetch/Response 的 Node.js：

```sh
python -m pip install playwright==1.51.0
python -m playwright install chromium
python tests/test_alphabet.py
python tests/test_alphabet_integration.py
python tests/test_practice.py
node tests/test_sw.cjs
```
